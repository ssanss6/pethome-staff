# frontend-staff（员工小程序）

员工端微信小程序：微信原生开发。

## 已实现

- 今日任务首页（写死数据：任务列表 + 类型筛选 + 打卡/上传占位）
- 账号密码登录（→ 后端 `POST /api/auth/login`）

## 目录

```
├── app.js / app.json / app.wxss
├── config\api.js               # 后端地址 http://127.0.0.1:8080
├── utils\request.js / auth.js  # 请求封装 + 登录态
└── pages\index（今日任务）、pages\login（账号密码登录）
```

## 运行

1. 微信开发者工具 → 导入本目录；
2. 勾选「不校验合法域名」；
3. 后端启动后登录。默认账号：`staff01 / 123456`。
